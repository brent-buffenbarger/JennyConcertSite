# Project Skills

Put project-specific opencode skills in subdirectories here.

Each skill should use this layout:

```text
.opencode/skills/<skill-name>/SKILL.md
```

Minimal template:

```md
---
name: example-skill
description: Use when the task matches this project's repeated workflow.
---

# Example Skill

Describe when to use the skill, what files matter, and what checks to run.
```
