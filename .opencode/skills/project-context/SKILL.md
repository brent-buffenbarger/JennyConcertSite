# Project Context

Use this skill at the start of work when the repository needs local context beyond the global agent instructions.

## Default Expectations

- Prefer minimal, targeted edits.
- Follow existing naming and file organization when the repository has established patterns.
- Do not introduce new tooling or dependencies without a concrete reason.
- Add lightweight verification when making behavior changes.
